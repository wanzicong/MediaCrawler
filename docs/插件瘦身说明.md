# MediaCrawler 插件瘦身说明

## 问题

插件市场配置 `"source": "./"` 指向仓库根目录时，Claude Code 安装插件会把**整个 git 仓库**（478 个跟踪文件，含 node_modules 残留、mcp_server、api、webui 等运行代码）拷贝到插件缓存，1.0.2 缓存达 **221 MB**。插件实际只需要 9 个清单/技能文件。

## 根因

Claude Code 插件机制（CLI 2.1.220 已确认）**没有** plugin.json 层面的 `include`/`exclude` 字段，`source` 必须是 git 仓库引用，安装时拷贝整个仓库快照，无法只挑文件。

## 解决方案（已实施）

主仓库添加 `.gitattributes` 导出忽略规则，利用 `export-ignore` 让 git 归档/导出时剔除运行代码，只保留插件必需的 9 个文件：

```
.claude-plugin/plugin.json        # 插件清单
.claude-plugin/marketplace.json   # 市场清单
.mcp.json                         # MCP 配置（HTTP 连接 127.0.0.1:8765）
commands/mediacrawler-help.md
skills/crawl-platform/SKILL.md
skills/mcp-server-ops/SKILL.md
skills/media-transcribe/SKILL.md
skills/read-crawl-data/SKILL.md
LICENSE
```

**限制说明**：`export-ignore` 对 `git archive` 和 GitHub 的源码 zip 下载生效。Claude Code 安装插件时若走 git clone 完整快照则仍会拿到全部文件——这是插件机制本身的行为，非本仓库可控制。本方案是主仓库侧能做到的最大瘦身；若需彻底只含 9 文件，需另建独立发布仓库（见 git 历史中文档版本）。

## 验证方式

```bash
git archive --format=tar HEAD | tar -t
# 输出应只剩上述 9 个文件 + .claude-plugin/、commands/、skills/ 目录结构
```
