# MediaCrawler MCP 插件使用指南

本仓库除爬虫本体与 MCP 服务外，同时是一个 **Claude Code 插件**：内置 MCP 服务配置、
4 个使用技能和 1 个帮助命令。

## 插件内容

| 组件 | 位置 | 说明 |
| --- | --- | --- |
| 插件清单 | `.claude-plugin/plugin.json` | 插件元信息（名称/版本/作者） |
| 市场清单 | `.claude-plugin/marketplace.json` | 让本仓库可直接作为插件市场被添加 |
| MCP 配置 | `.mcp.json` | 以 stdio 方式启动 `mcp_server` |
| 技能 | `skills/crawl-platform` | 7 大平台爬取的工具选择与参数填写 |
| 技能 | `skills/read-crawl-data` | 按 crawl_run_id 回读数据 |
| 技能 | `skills/media-transcribe` | 视频下载 → 转写 → 字幕流水线 |
| 技能 | `skills/mcp-server-ops` | MCP 服务启停、日志、局域网配置 |
| 命令 | `commands/mediacrawler-help.md` | `/mediacrawler-help` 查看使用指南 |

## 安装方式

### 方式一：作为项目本地插件（推荐给本仓库使用者）

```bash
git clone https://github.com/wanzicong/MediaCrawler.git
cd MediaCrawler
uv sync
```

在该目录启动 Claude Code，`.mcp.json` 会被自动识别（首次加载需确认信任），
`mediacrawler` MCP 服务即可用。

### 方式二：作为插件安装到 Claude Code

```bash
claude plugin marketplace add wanzicong/MediaCrawler
claude plugin install mediacrawler@mediacrawler-marketplace
```

## 前置条件

- 已安装 [uv](https://docs.astral.sh/uv/)（MCP 服务通过 `uv run` 启动）。
- 首次爬取前需完成平台登录（二维码），登录态保存于 `browser_data/`：

```bash
uv run main.py --platform xhs --lt qrcode --type search --keywords test --headless false
```
